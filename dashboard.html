A-Z Setup Guide

① Deploy to Render (Free)

Visit render.com, connect your daviddan-241/Would-final GitHub repo, set Runtime to Docker, and deploy on the free tier.

② Telegram Bot Setup

Message @BotFather, run /newbot, add it as Admin to your group. Get the group ID via @raw_data_bot.

③ Free Gemini AI Key

Go to Google AI Studio → Get API Key. Free tier gives 15 requests/min. Paste in Settings → AI Credentials.

④ Session Cookies (iOS Safari)

Create a Safari bookmark with this URL:

javascript:(function(){var c=document.cookie;if(!c){alert('No cookies. Log in!');}else{prompt('Copy cookies:',c);}})();

Log in to Twitter/TikTok/Instagram in Safari, tap the bookmark, copy the auth_token value.

⑤ Free Rotating Proxies

Sign up at Webshare.io — free plan gives 10 rotating proxies. Paste them as user:pass@ip:port in Settings → Proxy Nodes.
